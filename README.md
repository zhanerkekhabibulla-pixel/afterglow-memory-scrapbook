# AFTERGLOW — A Digital Scrapbook of Your Life

> *We don’t just save moments. We give them a place to live.*

**AFTERGLOW** — мобильное приложение для создания персональных цифровых альбомов воспоминаний в эстетике *Modern Vintage Scrapbook*. Пользователь загружает фотографии, видео, текст, детали дня и музыку, а искусственный интеллект помогает подобрать настроение, цветовую гамму и раскладку страницы, сохраняя полную свободу ручного редактирования.

Проект разработан в рамках **ArtTech Hackathon 2026**.

## О проекте

Обычная галерея телефона хранит тысячи разрозненных файлов, но теряет историю, атмосферу и контекст дня. **AFTERGLOW** объединяет три ключевых элемента:

1. **Memory (Воспоминания)** — фотографии, видео, текстовая заметка, дата, место, погода, люди и прикреплённая музыка.
2. **AI (Искусственный интеллект)** — анализ загруженных материалов (без выдумывания несуществующих событий) и предложение названия, настроения, цветовых акцентов и сетки-шаблона.
3. **Creativity (Творчество)** — ручное редактирование каждого элемента страницы как отдельного слоя.

---

## Основные возможности

- **Create Memory:** создание воспоминания с загрузкой фото/видео, текстом, деталями дня и добавлением музыки.
- **Music Integration:** прикрепление ссылки на трек/плейлист (Spotify, Apple Music, YouTube Music и др.) или выбор демо-трека; музыкальная карточка на странице и влияние настроения музыки на стиль альбома.
- **Три сценария оформления:**
  - *Ready-made Templates* — выбор из готовых сеток-шаблонов разворотов.
  - *Describe Your Design* — генерация параметров оформления по текстовому описанию пользователя.
  - *Create From Scratch* — сборка страницы с нуля.
- **Creative Editor:** независимые редактируемые слои (фото, текст, стикеры/рамки, музыкальная карточка) — перемещение, изменение размера, поворот, смена фона и текста без «склеивания» страницы в одну картинку.
- **Interactive Photos:** просмотр фотографии в увеличенном виде с возможностью переключиться на обратную сторону карточки и прочитать личную заметку, дату, место и имена людей.
- **Три эмоциональных настроения:** *Nostalgic*, *Joyful*, *Dreamy / Calm*.
- **Personal Archive:** сохранение всех созданных альбомов, сортировка по датам, избранное и возврат к редактированию.

## Дизайн-система

Визуальный стиль опирается на эстетику тёплых бумажных дневников и редакционных арт-журналов (*Modern Vintage Scrapbook*):

- **Типографика:**
  - `Libre Baskerville` — основной шрифт (заголовки, названия альбомов, акцентные подписи).
  - `Alegreya Sans` — второстепенный шрифт (интерфейс, кнопки, описания, заметки).
- **Цветовая палитра:**
  - **Dark Chocolate:** `#443025` (основной текст, рамки, акценты)
  - **Aloewood:** `#7F5836` (вторичные заголовки и тёплые элементы)
  - **Milk Tea:** `#AA7F66` (карточки и второстепенные поверхности)
  - **Sakura:** `#EC9C9D` (акцентные теги и детали)
  - **Misty Rose:** `#F2CF2A` (дополнительный акцент в палитре проекта)
  - **Paper Background:** `#F6F1E7` / `#EFE7DA` (фактурный бумажный фон страниц)

## Установка и запуск

### Предварительные требования
- **Node.js** версии 18 или выше
- **npm** / **pnpm** / **yarn**
- Приложение **Expo Go** на смартфоне (iOS / Android) или настроенный эмулятор

### Шаги запуска

1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com/<your-username>/afterglow.git
   cd afterglow
   ```

2. **Установите зависимости:**
   ```bash
   npm install
   ```

3. **Настройте переменные окружения:**
   ```bash
   cp .env.example .env
   ```
   Заполните ключи API в файле `.env` (см. раздел ниже). Если ключи не указаны, приложение автоматически запустится в автономном демо-режиме с локальным fallback.

4. **Запустите сервер разработки Expo:**
   ```bash
   npx expo start
   ```

5. **Откройте на телефоне:**
   - Отсканируйте QR-код из терминала через приложение **Expo Go** (Android) или камеру iPhone (iOS).
   - Либо нажмите `a` для запуска в Android Emulator / `i` для iOS Simulator.

## Архитектура данных и AI-логика

### Модель страницы
Каждая страница альбома хранит массив независимых объектов (`PageItem`), благодаря чему дизайн остаётся редактируемым после генерации и сохранения:

```ts
export interface PageItem {
  id: string;
  type: 'photo' | 'text' | 'sticker' | 'frame' | 'music';
  x: number;
  y: number;
  width: number;
  height: number;
  rotation: number;
  zIndex: number;
  data: Record<string, any>;
}
```

### Принципы работы AI
1. На вход подаются только данные пользователя: текст воспоминания, подписи/описание фото, метаданные (дата, место, погода, настроение) и прикреплённая музыка.
2. Модель возвращает структурированный JSON: заголовок, категорию настроения (`Nostalgic`, `Joyful`, `Dreamy / Calm`), акценты из утверждённой палитры и раскладку элементов по сетке-шаблону.
3. Системный промпт строго запрещает AI додумывать события, которых не было в пользовательском вводе.
4. При отсутствии сети срабатывает детерминированный локальный генератор пресетов.

## Статус реализации (Full vs Demo)

- **Полностью реализовано в прототипе:**
  - Навигация по основным экранам приложения.
  - Создание воспоминания с загрузкой реальных фотографий, текстом и добавлением музыкальной ссылки / демо-трека.
  - Выбор стиля (*Ready-made Templates*, *Describe Your Design*, *Create From Scratch*).
  - Редактор страницы с независимыми слоями (перемещение, масштабирование, редактирование текста и фона) и сохранением состояния.
  - Просмотр альбома и открытие фотографии с заметкой на обратной стороне.
  - Архив воспоминаний и 3 предзаполненных демонстрационных альбома (*Nostalgic*, *Joyful*, *Dreamy / Calm*).
- **Демонстрационный режим:**
  - Анализ изображений и аудиотреков работает на основе пользовательских описаний, метаданных и AI-генерации конфигурации макета (без скачивания защищённых аудиопотоков сторонних стримингов).
